# discord-vocal-stats-bot

Bot Discord de statistiques et de présence vocale avec détection du mode sourdine.

## Configuration (.env)

```ini
TOKEN=ton_token_discord
CLIENT_ID=id_du_bot
GUILD_ID=id_du_serveur
LOG_CHANNEL_ID=id_salon_logs_carlbot
STATS_ID=id_salon_annonces_stats
```

## Lancement de développement

```bash
# Installation des dépendances
pnpm install

# Formater le code
pnpm format

# Compiler et lancer en dev
pnpm run build
pnpm run start
```
